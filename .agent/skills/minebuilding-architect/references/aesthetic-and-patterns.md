# 造形美学・構造パターン・アンチパターン集

過去の複数大規模建築セッションの視覚検証・失敗修正から蒸留した、**テーマ非依存の造形・配色・構造エンジニアリング指針**。

---

## 1. 配色・テクスチャリングの鉄則（アンチ・コンフェッティ法）

### 禁止：高彩度ブロックのランダムノイズ散布
- 色相や明度が大きく異なる高彩度ブロックを `h3(x,y,z)` で1マス単位にランダム散布すると、遠景では「紙吹雪ノイズ（チカチカ）」、近景では「意図のないゴミ模様」に見える。
- 白壁・漆喰面へ3種以上の雑多な白系ブロックをランダム混色するのも近景で汚く見えやすい。

### 推奨：連続関数グラデーション＋意図的帯構造
1. **連続スカラー場による帯状遷移**：
   - 地層・風化・温度・エネルギー密度などは、高さ `relY`・中心距離 `r`・角度 `theta`・螺旋位相などの連続関数に **低周波 2–3 オクターブ `fbm3D`（空間周波数 `0.07..0.18`）** を穏やかに加算し、`pickFromGradient(t, stops)` で帯状に切り替える。
   - 地表の鉱脈・変色帯を連続の白い直線にすると人工的に浮くため、周囲の岩材と混ぜて `<16%` の控えめな点在に留める。
2. **パレット上限（モジュール／オブジェクト単位で ≤ 3トーン原則）**：
   - この原則は**建築モジュール単位、または個別の自然物・天体オブジェクト単位**に適用する（1つの塊を多色お祭り化させないためのルール）。
     - 例（建築モジュール）：**明色壁材**（`smooth_quartz` / `calcite` / `white_terracotta`）＋ **暗色構造フレーム**（`deepslate_bricks` / `polished_deepslate` / `deepslate_tiles`）＋ **金属・温色アクセント**（`cut_copper` / `smooth_sandstone` / `gold_block`）。
   - **複合テーマ作品と色温度コントラストは別予算**：主建築と背景の自然地形・天体・発光帯などを組み合わせる複合シーンでは、各オブジェクト／テーマごとに独立した3トーン予算と**暖色／寒色の色温度コントラスト**を持たせ、シーン全体が単調・色褪せ（ウォッシュアウト）になるのを防ぐ。
   - 同一ファミリー内のテクスチャ混色（例：石レンガ＋ひび割れ＋安山岩）は明度差が小さい3〜4種に抑え、漆喰壁は単一主材＋**規則的な水平帯（`y % 6 === 0` のコーニス）**で品格を出す。
   - 木材等の第4素材は、桟橋・手すり・室内家具など人間スケールの機能部位に限定する。
3. **色温度の明確な役割分離**：
   - **暖色光源**（`lantern`, `ochre_froglight`, `shroomlight`, `campfire`）：居住区・通路・街灯・窓のバックライト。
   - **寒色光源**（`soul_lantern`, `sea_lantern`）：動力コア・機械機構・水中／深淵・幻想的アクセント。
4. **透過ガラスヴェールと外縁フェード**：
   - 雲・霧・エネルギー・発光帯は、内芯に発光ブロックを埋め込み外殻を `*_stained_glass` で包むと立体感と未減衰の発色が出る。
   - 暗背景や虚空に接する外縁に高彩度の蛍光色ガラス（例：`magenta_stained_glass`）をそのまま置くと縁が安っぽく浮く。暗色ガラス（`purple` → `black_stained_glass`）へ段階フェードさせ、外縁を密度カットオフでかすれさせる。

## 2. 立体構図・奥行き・シルエット設計

1. **平面配置の打破（Y軸＋斜め軸＋ネガティブスペース）**：
   - 建築を単一 Y 平面に並べず、**ワールド高さの 70〜90% を縦に使う高低差**（地下／下部構造・主階層・高層尖塔／上部機構）を設計段階で確保する。
   - 水平面ばかりだと俯瞰が単調になりやすいため、動的な主題では `makeOrthonormalBasis()` で **`28°–38°` 傾斜した正規直交基底 `(U, V, N)`** を導入し、構造物が画面を斜めに貫く立体構図を作る。
   - **ネガティブスペース（抜け感）を最優先で守る**：中央に無意味な塊を詰めず、吹き抜け・空洞・暗色ギャップ（主役と周囲の間に1–2マスの明確な抜け）を設計する。主役シルエットを邪魔する装飾リングや細い「アンテナ状パーツ」は視覚チェックで迷わず削除する。
2. **2〜3層の壁面ディテールとシルエットの鋭さ**：
   - 平坦な1層壁を禁止。柱・控え壁（バットレス）を1ブロック外側へ出し、窓は1ブロック凹ませて内側奥にバックライト（`shroomlight` 等）を仕込む。
   - 軒先・張り出しの下端は逆さ階段（`half: "top"`）のコーベルや階段＋ハーフ＋塀＋鉄格子で先端を細く絞り、ずんぐりした箱・鈍い尖塔を避ける。
   - **スケール対比**：100〜250ブロック級の巨大造形には、人間スケール（ドア高2・欄干高1・街灯高4–5）の建築要素を1箇所以上添えると圧倒的なサイズ感が伝わる。
3. **二重面・外周面の文字／記号反転防止ルール（重要）**：
   - 看板・文字盤・紋章などの2Dビットマップを壁面の**内側と外側**の両方に刻むとき、単一の座標軸（例：`+X`）を共有すると**片側が必ず鏡像反転**する（実例：外周時計塔のローマ数字が外側から `XI` / `IV` / `IIX` に反転した。Linter では検知不可）。
   - **鉄則**：必ず外向き法線 `outwardNormal` から水平右方向ベクトル `right = cross([0,1,0], outwardNormal)` を導出する（`geometry_helpers.js` の `stampGlyphPlane()` を使用）。

## 3. 中空シェル＆6近傍連結の建築エンジニアリング

### 1. 有機体・岩塊の気密中空シェル（26近傍表面抽出＋6近傍BFS）
- 浮島・岩山・小惑星・太い柱などの体積物をベタ塗りすると即座にブロック上限（24万）を突破する。
- **落とし穴**：3Dマスクから「6近傍に空気があるセル」だけを抽出すると、曲面や斜面の角接点が6連結を失い、**数千ブロック・数百クラスタの浮遊破片**が発生する。
- **解法（`geometry_helpers.js` の `buildHollowVolumeShell`）**：
  1. `Uint8Array` の3D内部マスクを生成。
  2. 接地・接続面をシードに **6近傍BFS** を回し、ノイズ由来の孤立小片をマスク段階ですべて除去。
  3. **26近傍（Chebyshev 半径 `1`、後から室内を掘削する区域は半径 `2`）** に空気があるセルのみ出力。これにより斜面の内側角が自動で補完され、**浮遊ブロック0個・気密な1層中空シェル**が数学的に保証される。

### 2. 6連結を絶対に切らさない幾何イディオム
- **斜め支柱・トラス・ケーブル（`drawStrut` / `drawCatenary`）**：単純な `lerp` や `sin/cos` サンプリングは `(x+1, z+1)` の斜め飛びを起こして浮遊クラスタを生む。前回座標 `(prevX, prevY, prevZ)` から **1軸ずつ（X→Z→Y）マンハッタン歩進**して完全に6連結させる。
- **中空テーパー円錐・ドーム・尖塔の層間オーバーラップ**：Y が1段上がるごとに半径が縮む中空殻で固定厚 `r >= sliceR - 1.15` を使うと段差が斜め接触のみになり分離する。必ず次層（または前層）半径と重ねる：
  - 矩形尖塔：`abs(dx) >= nextHalfW || abs(dz) >= nextHalfD`
  - 円形ドーム：`innerR = Math.min(sliceR - 1.15, Math.max(0, nextR - 0.5))`
- **中空ボックス断面リング（`isHollowRimVoxel`）**：大型リングや円筒壁は、上下蓋＋内外1ブロック厚スキン（`0.85`）＋一定角度ごとの内部リブ（`arcDist <= 0.6`）で中空化すると視覚差ゼロで数万ブロック削減できる。
- **縁限定土壌（Rim-Gated Soil）**：崖・渓谷地形で高さ閾値だけで草土を置くと中腹の岩棚まで不自然に緑化する。列ごとの最頂面 `plateauTop[x][z]` を記録し、`y >= plateauTop - 2` にのみ草土を限定する。

## 4. バニラ Minecraft 整合イディオム（Linter 警告0件の標準部品）

1. **鎖（`iron_chain`）の T字・L字直結禁止**：
   - 横向き鎖（`axis=x/z`）の途中から縦鎖（`axis=y`）や吊りランタンを直接下げない。
   - **Zero-T-Chain 街灯**：`*_wall` 台座 → `*_fence` 支柱 → `*_wall` 継手＋ハーフ帽 → 水平 `*_fence` 腕 → 垂直 `iron_chain[axis=y]` → `lantern[hanging=true]`。
   - **吊り橋・クレーン**：主ケーブルは階段・`*_wall`・フルブロックで組み、吊り下げ点の中継ブロック直下からのみ垂直 `iron_chain[axis=y]` を下ろす。
2. **ツタ（`vine`）＆ヒカリゴケ（`glow_lichen`）の支持保証**：
   - 張り付き先は `FULL_OPAQUE_BLOCKS` のみ（塀・フェンス・階段・ハーフ・ガラス・葉は Linter で `missing_support`）。
   - 垂れ下がりツタは `placeHangingVineSafe()` で **最上段 `yTop` の水平4近傍にフル不透明キューブがある位置**から下へ伸ばす。
3. **ステージ原子性（Stage Atomicity）**：
   - 段階ビルドで「Phase A に吊りランタン、Phase B に上の天井」と分割すると中間チェックが落ちる。支持体は必ず同一フェーズ内で配置する。
4. **橋脚・柱の上書き防止**：
   - 連続手すり・欄干ループでは端点（`i === 0 || i === steps`）をスキップし、橋脚柱をハーフブロックやフェンスで分断しない。

## 5. マルチアングル視覚検証＆失敗アンチパターン早見表

### 必須カメラ 4〜5 アングル（毎回固定視点で差分比較）
1. **主斜め俯瞰（Hero Oblique）**：`projection="perspective"`, `resolution=768`。傾斜面がある場合は `dot(camDir, N)` を計算し、面がエッジオン（真横）にならず `20°–30°` 開く `yaw`/`pitch` を選ぶ。
2. **反対側リバース俯瞰（`yaw + 180°`）**：**必須**。正面からは美しいのに背面から見ると片面シェルが主役を塞ぐ・裏面の文字が鏡像反転している致命傷を確実に捕捉する。
3. **前景越しフレーミング視点 / 低仰角あおり視点（`pitch = -5°..+12°`）**：45°正投影では潰れる縦の迫力・渓谷の奥行き・手前建築の遮蔽（主役を隠していないか）を確認。
4. **建築ディテール超近接（`distance = 20..40`）＋ `inspect_pixel`**：街灯・鎖継手・窓・文字盤・ツタ・階段角などのバニラ整合性とシルエットを検証。

### 過去ログから抽出した失敗アンチパターン早見表

| 失敗アンチパターン | 視覚・検証上の症状 | 汎用修正策 |
|---|---|---|
| 高彩度ブロックのランダム散布／雑多な白壁混色 | 遠景がチカチカ（紙吹雪）、近景が汚い斑点 | 連続関数＋低周波 `fbm3D` の帯状グラデーション、壁面は単一主材＋規則水平帯 |
| 暗背景外縁の蛍光色ガラス（`magenta` 等） | 輪郭がネオンピンクに浮いて安っぽい | 暗色ガラス（`purple` → `black_stained_glass`）へ段階減衰＋外縁密度カットオフ |
| 主役と競合する細リング・装飾帯の過積載 | ネガティブスペース喪失、おもちゃ感 | 競合装飾を削除して暗黒・空の抜けを確保し、主建築の繊細化へ予算再配分 |
| 6近傍空気判定での曲面中空シェル抽出 | 斜面に数千ブロック・数百クラスタの浮遊破片 | `buildHollowVolumeShell`（6近傍BFS＋**26近傍**表面抽出）に切替 |
| `lerp` 斜め支柱・単層テーパー円錐の分離 | 1〜数十ブロックの点状浮遊クラスタが大量発生 | マンハッタン歩進 `drawStrut`・次層半径とのオーバーラップ `min(r-1.15, nextR-0.5)` |
| 二重面ビットマップの単一軸描画 | 外側面だけ文字・数字が鏡像反転（Linter 素通り） | `stampGlyphPlane` で外向き法線から `right = cross(up, N)` を導出 |
| 片面前提の3Dアーチ／フード造形 | 正面は良好だが `yaw+180°` 背面から主役が完全に遮蔽 | 前後対称窓（`Math.abs(cosFace)`）で 360° 全周から主役が見える設計にする |
| 直線1ブロックの硬直した軌跡・垂れ尾 | 棒付きキャンディ状の不自然な硬直 | 局所接線基底での緩やかなカーブ＋大小中空破片の有機的オフセット |
| カメラ手前の地形縁・前景建築による視線遮蔽 | 主役や下部構造が壁・塔の裏に隠れる | 視点側の地形縁を段々低く削り、前景要素は画面端3分の1へ配置 |
| 望遠鏡・砲身等の直線部品の自己貫通 | 対象方向ベクトル直進で自棟のドーム縁や床に刺さる | 設置高を引き上げ仰俯角をクランプ＋近接カメラで視線クリアランス確認 |
| 橋・手すりループによる橋脚端点の上書き | 支柱の付け根がハーフブロックや柵に置換され途切れる | 端点 `i === 0 || i === steps` で手すり配置をスキップ |
| `chain`（旧ID）やサンドボックス内 `jarFound=false` 描画 | 鎖がただの箱・ガラスが不透明キューブに化ける | `minecraft:iron_chain` を使用し、実 JAR 接続（`jarFound=true`）を必ず確認 |
| 横向き鎖への縦鎖／ランタン直結、非フルブロックへのツタ | `lint_structure` で `axis_mismatch_junction` / `missing_support` | `placeChainSafe` / `placeLanternSafe` / `placeHangingVineSafe` ＋中継ブロック徹底 |
| 空中建築で未アンカーのまま構造検証を実行 | 意図した浮遊クラスタが大量の `floatingBlocksCount`・構造警告ノイズとして報告される（`lint_structure` 自体は100件上限で安全終了） | 事前に `dry_run_validator.mjs --emit-anchors` でクラスタ別の元ブロックID・ステートを忠実継承した `isTerrain=true` アンカー `.nbt` を生成し `floatingBlocks: 0` にする |
